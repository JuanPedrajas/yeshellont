Yes Hello, !

It's ok to say hello.

It's ok to start a message with a greeting.

It's ok to ask how someone is doing first.

It's ok to be a human being talking to another human being.

Software is built by people, and people are not API endpoints. A 'hello' costs nothing and tells the other person: you matter.

The opposite of nohello is not chaos. It is warmth. Send the hello. Wait for the reply. The world will keep turning.
